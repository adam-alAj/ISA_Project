# Smart Vacuum Brand Guide

## Core Identity

- Name: Smart Vacuum
- Tagline: Precise route intelligence for autonomous cleaning.
- Personality: precise, calm, scientific, trustworthy
- UI voice: short, factual, operational

## Logo System

Assets:

- `assets/brand/logo.svg` (primary lockup)
- `assets/brand/logo_mark.svg` (compact mark)
- `assets/brand/app_icon.ico` (Windows multi-size icon)

Construction:

- Rounded tile + robot-disc mark + path motif
- Geometry tuned for legibility at small app/icon sizes
- Original artwork created for this repository (no third-party trademark/sponsor marks)

Usage rules:

- Minimum lockup height: 20 px
- Minimum mark size: 16 px
- Clear space: at least half the mark radius on all sides
- Keep sufficient contrast against background surfaces

Variants:

- Light surface: full color
- Dark surface: use mark and wordmark with high-contrast light text
- Mono: single-color mark for narrow utility contexts

## Typography

- Primary UI family: DejaVu Sans (bundled offline)
- Fallbacks: Segoe UI Variable, Segoe UI, sans-serif
- Files:
  - `assets/fonts/DejaVuSans.ttf`
  - `assets/fonts/LICENSE_DEJAVU.txt`

## Iconography

- Project icons bundled under `assets/icons/`
