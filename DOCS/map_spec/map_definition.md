# Department map v0.3 definition (draft)

## Boundary and occupancy

The simulated floor includes the open hall, entrance, and interiors of R1–R8 plus R7b. Geometry is defined in `elements.yaml` and generated by `src/map_processing/build_department_map_v03.py`. The hall zones, doors, fixed obstacles, and start are preserved from v0.2. R4, R5, and R6 outer edges were adjusted to satisfy the confirmed size ordering; room dimensions remain proportion-derived estimates, not measurements.

Cells outside traced zones and room interiors are `OCCUPIED`. `UNKNOWN` is reserved and currently unused. `CLEANED` is a separate boolean layer. The source photo is still missing, so interpretation of the drawing is pending.

## Doors and movement

All nine doors are permanently open passages in v1.0. Grid movement is four-neighbor in fixed order Up, Right, Down, Left; diagonal transitions are not used. The 0.10 m cell size is provisional.

## Start and demo goals

The default start is S at `(118,54)`. The around-column case uses `(36,68)` only as the explicitly named `around_column_alternate_start` scenario variant in `demo_config.yaml`; its goal is `(36,78)`. The other seven department-map goals use S. The synthetic no-path case uses a separate 1×3 test map. The listed demo set remains provisional pending instructor clarification.
