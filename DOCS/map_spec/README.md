# Department map v0.3 draft specification

This directory records the human-assisted traced map with the user-directed room geometry correction. v0.2 remains preserved unchanged; v0.3 is a separate draft and is not frozen. Geometry source: `src/map_processing/build_department_map_v03.py`.

Read `map_definition.md`, `elements.yaml`, `dimensions.csv`, and `consistency_report.md`. The regenerated map preview is `annotated_plan.png`; demo starts and goals are described in `demo_goals.csv` and `demo_config.yaml`. Independent raster checks are in `validation.md`. Python and the original source photo are unavailable in this environment, so Python execution/pytest and source-dependent visual verification remain outstanding.
