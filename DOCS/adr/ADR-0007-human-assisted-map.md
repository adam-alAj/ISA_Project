# ADR-0007 Human-assisted map pipeline

## Context
The supplied department plan is hand-drawn and traced geometry is already available as v0.2 artifacts.

## Decision
Treat digitization as human-assisted. Preserve and review the source drawing and existing v0.2 map; do not claim general automatic floor-plan recognition or regenerate the map during P0.

## Consequences
Map geometry and assumptions require human review. The original source photo must be added when supplied; current workspace contains the map array, metadata, and preview only.

## Status
Proposed — preserves the established project rules.
